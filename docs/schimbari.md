# Jurnal de modificări

## Format

```
## <data> — <titlu scurt>

**Cerere:** <ce a cerut utilizatorul>
**Fișiere atinse:** <lista>
**Ce face:** <efectul concret în joc>
**Recompilare:** <da/nu>  •  **Patch client:** <da/nu>  •  **Modificări DB:** <da/nu>
**Rollback:** <pașii exacți>
**Commit:** <hash>
```
